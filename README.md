# Fayrouz (فيروز)

> **System 1 Coffee Matcher** — Connect your palate to the coffee shop menu in 3 seconds.

## Concept
Fayrouz eliminates menu decision fatigue at specialty coffee shops. Instead of reading 30 complex menu options, Fayrouz presents:
- **3 Safe Matches** (with #1 Perfect Match highlighted for 1-tap ordering)
- **1 Adventure Pick** ("Wanna try something new?")

## Tech Stack
- **Frontend**: Next.js 15 (App Router) + Tailwind CSS
- **Backend & Database**: Firebase (Firestore, Auth, Storage)
- **AI**: Gemini for menu scanning and personalized taste translation
- **Target Domain**: `fayrouz.bynoor.io`
